## 📖 What is Poké Context Memory?

**Poké Context Memory** is a browser extension that acts like a *Pokédex for your AI conversations*.  
It lets you **capture** the most important entities, decisions, and summaries from any chat with an AI model, **store** them locally as structured Contextémon™, and then **inject** them into a new chat — so you never lose context memory again.

Think of it like throwing a **Poké Ball** at your conversation: the extension extracts the essence, turns it into a compact, searchable artifact, and lets you summon it on demand. All of this runs **100% in your browser** — no backend servers, no cloud, your data stays with you.

---

## ✨ Core Features

- 🧠 **Auto‑Capture** – Intercepts messages from ChatGPT, Claude, Gemini & more (site adapters included).
- 📦 **Local AI Summarisation** – Uses a small, offline language model (Transformers.js) to distil chats into concise summaries and extract key entities (decisions, code, dates).
- 🧬 **Semantic Search** – Find any past context by meaning, not just keywords, thanks to local embeddings + vector search (no server needed).
- 💉 **One‑Click Injection** – Paste a saved context directly into any supported AI chat input field, formatted as clean Markdown the model understands effortlessly.
- 📁 **JSON + Markdown Export** – Export your Contextémon as structured `.json` (for re‑import) or beautiful `.md` (for sharing).
- 🔒 **Fully Offline & Private** – Everything runs in your browser. No external API calls, no telemetry.
